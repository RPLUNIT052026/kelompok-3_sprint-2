## 🌸 ABOUT THE PROJECT

**ClosetGirls ThriftShop** merupakan proyek website toko pakaian thrift yang dirancang untuk memudahkan pengguna dalam mencari, melihat, dan memilih produk thrift.

Fitur yang dirancang meliputi registrasi, login, beranda, pencarian produk, katalog, detail produk, keranjang, checkout, profil, dan keluar akun.

# 🚀 SPRINT 02 — SYSTEM DEVELOPMENT MISSION

**Product Release 2 · October 2026**

Sprint 2 berfokus pada pemodelan sistem, pengembangan, pengujian, dan penyempurnaan proyek ClosetGirls ThriftShop.

## 🪐 01. SYSTEM MODELING

Tahap ini digunakan untuk menggambarkan interaksi pengguna dengan sistem serta alur proses yang akan dikembangkan.

- [x] **Context Diagram**
  - Mengidentifikasi entitas eksternal yang berinteraksi dengan sistem.
  - Menggambarkan hubungan Pembeli, Admin, dan Sistem ClosetGirls ThriftShop.
  - Menjelaskan aliran data masuk dan keluar sistem.
  - Menyimpan diagram dalam format PNG.
  - Menambahkan dokumentasi Context Diagram.

- [x] **Use Case Diagram**
  - Mengidentifikasi aktor Pembeli dan Admin.
  - Menggambarkan fungsi yang dapat dilakukan setiap aktor.
  - Memetakan fitur sistem seperti registrasi, login, pencarian produk, katalog, detail produk, keranjang, checkout, profil, dan logout.
  - Menggambarkan hubungan aktor dengan setiap use case.

- [x] **Sequence Diagram**
  - Menggambarkan urutan interaksi aktor dengan sistem.
  - Menunjukkan urutan pesan dalam proses yang dipilih.
  - Menjelaskan alur interaksi untuk fitur utama, seperti login, pencarian produk, dan checkout.
  - Menyimpan diagram dan dokumentasinya.
